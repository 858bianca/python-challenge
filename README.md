To complete the calculations the dataset was composed of three colums: "Voter ID", "County", and "Candidate". Second, was to create a complete list of candidates, which aids in identifying all unique candidates that received a vote. Afterwards, a calculation was created to get the precentage of votes per each candidate, this gives us the total percentage of votes each candidate received. Which than leads the total of number of votes each candidate won, this easly summarizes the total number of votes received per candidate. Lastly, a calculation was created to print out the winner of the election. 

At the end the script should demonstrate an efficient solution in analyzing the election data and efffectively determine the highest candidates with votes and the overall winner of the election.
